# Login Bug Report

## Title
Login button does not work with valid credentials

## Environment
- Application: SauceDemo
- Browser: Chrome
- Environment: Test

## Steps to Reproduce
1. Open the login page.
2. Enter valid login credentials.
3. Click the Login button.

## Expected Result
User should be successfully logged in and redirected to the Products page.

## Actual Result
User is not logged in and remains on the login page.

## Severity
High

## Priority
High
