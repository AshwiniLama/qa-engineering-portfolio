# Login Bug Report

## Title
Login button does not work with valid credentials

## Environment
- Application: Web Application
- Browser: Chrome
- Environment: UAT

## Steps to Reproduce
1. Open the login page.
2. Enter a valid email address.
3. Enter a valid password.
4. Click the Login button.

## Expected Result
User should be successfully logged in and redirected to the dashboard.

## Actual Result
User remains on the login page and is not logged in.

## Severity
High

## Priority
High
